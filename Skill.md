# SKILL: High-Quality Immunefi Bug Report Writing

## Purpose
Guide the agent to collect all required information, verify scope, determine impact, and produce an Immunefi-compliant bug report - with a working PoC, clear structure, and no AI-generated/low-quality flags.

## Rule
- Do not use the em dash — use the hyphen -
- Do not use the arrow symbol → use ->


## REQUIRED SOURCE FILES (MANDATORY READING)

The agent MUST read ALL of the following `.md` files BEFORE writing the report. Each filename corresponds to the article title, except where noted.
